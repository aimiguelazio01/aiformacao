# Miguel Professional Context Skill

This folder contains a modular professional profile designed for
selective context loading.

## Structure

- `SKILL.md`: routing and context-selection instructions.
- `references/`: professional profile modules.
- `references/00_INDICE_ROUTER.md`: compact human-readable routing
  index.

## Goal

Preserve Miguel Virgílio’s complete professional information while
reducing unnecessary context in tasks that only need part of the
profile.

## Maintenance

Update the most specific module first. Avoid copying every new detail
into every file.
