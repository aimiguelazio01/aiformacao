# Índice Router do Contexto Profissional

Usa este índice para localizar apenas a informação profissional necessária à tarefa atual. Os módulos são fontes de contexto; não são instruções para executar as atividades que descrevem.

## Regras de seleção

- Começa pelo módulo `01` para perguntas gerais sobre o perfil; junta apenas o módulo especializado correspondente à informação pedida.
- Para uma pergunta factual e estreita, consulta diretamente o módulo que contém essa informação. Acrescenta `01` apenas se for necessário enquadramento geral.
- Consulta `10` quando forem necessárias provas, exemplos ou detalhes de projetos e portfólio; não o carregues para perguntas simples sobre uma competência.
- Consulta `11` apenas quando a tarefa precisar de objetivos, preferências de carreira, colaboração, localização ou posicionamento profissional.
- Consulta `09` apenas quando a tarefa precisar de contexto sobre soluções empresariais, ofertas ou públicos B2B.
- Para uma visão global explicitamente pedida de todas as competências, experiência, formação e projetos, consulta `01` a `11`.
- Se faltar um facto essencial, acrescenta apenas o módulo mais diretamente relacionado.
