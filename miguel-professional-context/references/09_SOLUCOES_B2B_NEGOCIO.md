# Soluções Empresariais / B2B

## Base empresarial

Formação académica: **Licenciatura em Gestão de Empresas**.

## Objetivo

Combinar experiência criativa e tecnológica com IA para criar soluções
acessíveis para PMEs e outras organizações.

## Soluções

- Aplicações internas
- Automação de processos
- Interfaces inteligentes
- Reconhecimento visual
- Aplicações para restauração
- Soluções para oficinas
- Soluções para escolas e creches
- Experiências comerciais interativas
- AR
- Aplicações web
- Protótipos rápidos
- Sistemas personalizados
- Computer vision
- Experiências 3D e imersivas
- Formação em IA

## Abordagem

Identificar problemas concretos de negócio e construir
protótipos/soluções funcionais através da combinação de 3D, real-time,
web, sensores, computer vision e IA.

## Público prioritário

PMEs e organizações que necessitem de soluções personalizadas sem
depender de projetos de software tradicional excessivamente complexos.
